# Folio 1.0.7 · 退出时更新

在安装版中点一次「帮助 → 检查更新」。有新版时会自动下载，你可以关掉更新窗口继续阅读。正常退出 Folio 时会完成安装，下次打开就是新版。下载尚未完成时退出，Folio 会先等下载与校验结束。系统若要求授权，请按提示确认。

Windows x64 使用现有安装程序，macOS 的 Apple Silicon 和 Intel 各自获取适配的签名更新，Ubuntu x64 使用系统软件包管理器。更新前会保存工作区。仍在编辑笔记或生成回答时，Folio 会保留窗口，让你完成手头的工作再退出。

**从旧版过渡**　Windows 1.0.2–1.0.6 用户最后一次按原流程下载并选择「重启并更新」。旧版 macOS 和 Linux 用户最后一次从该发布页安装对应的 DMG 或 DEB。装好 1.0.7 后，后续版本都能从帮助菜单更新。

本版包含 1.0.6 对加号菜单九种输出的修复，保留现有文献库、笔记、设置和对话。
