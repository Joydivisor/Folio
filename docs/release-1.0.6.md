# Folio 1.0.6 · 加号菜单输出修复

点击输入框左侧的「＋」或输入 `/`，可以选择交互可视化、流程图、分步推导、对照表、三维演示、结构示意、关系图、过程演示或文字解释。每种选择都有对应的模型指令和结果校验。

- 流程图会检查判断分支的条件。关系图在同一份回答中交付节点与连线。对照表会核对每行的列数。
- 三维演示会核对题目指明的几何体。交互置换按原文的循环记号核对映射。可以要求先用一两句话介绍，再呈现所选图表。
- 模型返回残缺数据或选错形式时，Folio 会带着具体问题自动重试一次。连续两次未通过时，输入框保留原问题、引用和格式，可以编辑或重试。需要补充材料时，下一轮沿用所选格式，重启后也可继续。

真实模型复测使用 DeepSeek Flash 和九道有已知结果的例题。每种输出重复两次，共 18 次通过，均在第一次响应中给出匹配的结构。检查内容包括置换映射、判断回路、方程结果、表格数值、三维旋转和滑块的运动方向。这组结果限于所测模型与题目。

Windows 安装版可在「帮助 → 检查更新」中下载并重启安装。macOS 和 Linux 用户可在本页下载对应安装包。
