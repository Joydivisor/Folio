# beta.10 r3 界面一致性验收

用户要求从四处截图问题扩大到整个应用检查。本次沿着「点击／键盘／拖动 → 页面状态变化 → 控件与内容呈现 → 本地保存」检查文献库、阅读、画布、笔记、设置及二级弹窗；不改模型输出协议。

## 共用组件修正

| 范围 | 修正 |
| --- | --- |
| 完整推导 | 保留全部步骤连续阅读，删除无实际翻步作用的上一步、下一步、播放控件和当前步骤描边。真正的交互实验仍保留控制。 |
| 输入与搜索 | 用同一套颜色和焦点规则；文献库组合搜索框只在外层显示柔和提示，内部输入框不再出现第二圈边框。覆盖批注、笔记、功能说明、全文搜索及附件搜索。 |
| 选择菜单 | 阅读模式、筛选排序、设置、版本历史、分类和文献资料统一使用应用菜单。阅读模式有用途说明；支持选中标识、禁用状态、方向键、Home/End、回车／空格、Esc 与焦点返回。动态弹窗自动接入，关闭后清理菜单及监听器。 |
| 分段切换 | 画布／笔记、网格／列表及已有分段控件共用滑块；点击平滑移动，水平拖动跟手并在松开后停到选项。键盘操作、隐藏标签、笔记数量变化和减少动态效果设置均保留。 |
| 二级界面 | 统一弹窗标题、关闭按钮、字段、按钮尺寸及间距；作品选项增加图标、简短说明与版本历史分区；分类补充可见字段标签，修正颜色按钮比例。 |
| 主操作 | 保存文献资料、保存学习笔记、分类保存使用可读的主按钮配色，避免浅色背景上的白字。文件选择按钮与主题保持一致。 |

样式由 `public/controls.css` 管理，选择菜单由 `public/select-menu.js` 管理，分段切换由 `public/segmented-control.js` 管理。新建二级菜单应继续使用这些共用组件，避免再次出现系统原生选择框与应用菜单混用。

## 验证结果

- 自动回归 121 / 121 通过；105 个模块语法检查通过。
- 原始 PDF 选文、批注、拖入与笔记回归通过；真实双栏 PDF 的 17 项交互检查通过，文字层位移为 0 px。
- 打包后的运行文件逐字核对通过，包括 r3 修订号、两项新增控件资源、根目录白名单、凭据模式及资源路由检查。
- 直接从最终 app.asar 重跑 beta.10 连续阅读、混合图文、Anatomy 与网格回归通过。
- `scripts/test-controls.cjs` 的 12 类界面流程与 8 个组合通过：浅色／深色 × 1450／980 像素宽度 × 中文／英文。
- 五个设置分区、五个主菜单，以及文献资料、附件选择、分类、作品选项、学习笔记、目录搜索、备份、恢复和 Zotero 弹窗均纳入检查；检查布局溢出、可见原生下拉框、按钮文字可读性及渲染异常。
- 实际指针操作验证画布／笔记拖动；实际键盘事件验证菜单选择、Esc 只关闭当前菜单及恢复焦点；减少动态效果会关闭滑块动画。

截图和详细记录位于 `tests/reports/controls/`，其中有浅色、深色、宽窄窗口和不同二级界面的截图。界面测试使用独立资料库和固定模型响应，没有读取个人文献或调用真实模型。

本地安装包及安装后启动结果汇总到 `releases/verification/beta10-local.json`；r2 安装包和记录保留在 `releases/local-only/beta10-r2/`。

本机 r2 → r3 覆盖更新的 7 项检查通过；47 项运行资源与实际版本接口验证通过，已用原有默认资料目录启动新版。原生桌面截图工具在一次恢复重试后仍返回 `FrameArrived timed out: timed out waiting on channel`，因此没有把这一项写为通过；上面的界面截图及交互验证来自最终打包资源在独立 Electron 窗口中的实际渲染。
