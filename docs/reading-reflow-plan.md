# Beta.9 revision: unchanged PDF appearance

The separate Reading view has been removed following user feedback. The default PDF canvas is unchanged. Text spans retain their PDF.js font, position and transform, but their DOM order is organized by paragraph/column. Native selection remains available; a hover paragraph button and triple-click select whole paragraphs, with Shift for extension.

Drag-to-AI is direct. Feedback renders outside the sidebar clipping context, with explicit ring dimensions so global icon styles cannot collapse it. It lasts 1.6 seconds and has a non-animated receipt under reduced motion.

Existing notes and annotations are retained. The first-import snapshot repair remains included. Complex rotated pages keep the original text layer; scanned pages still need OCR. This is local layout processing, not a reproduction of Scholaread’s private AI algorithm.
