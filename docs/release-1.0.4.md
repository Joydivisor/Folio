# V1.0.4 · 阅读格式与交互更新

日期：2026-11-06。内部构建修订 r3，基于 V1.0.2。新增 DOCX、扫描 PDF 文字识别、输出方式选择和先引用再提问，并修正图示控件与笔记交互。

## 阅读文件

- 新增 DOCX，以及 Markdown 的 `.markdown` 扩展名。导入、文件夹扫描、文献附件、Zotero 附件与来源重新定位使用相同格式范围。
- DOCX 在本地从 ZIP 内的 WordprocessingML 读取正文，保留段落、表格单元格分隔、显式分页和常见公式的文本结构；不执行嵌入代码、外部链接或宏。
- DOCX 为文字重排阅读，引用位置是 Folio 分段，不是 Word 印刷页码。图片、复杂公式与精确排版请导出为 PDF；不支持旧 `.doc`、加密文档或宏文档。

## 扫描 PDF

原生文字页沿用原有 PDF.js 流程。缺少可读文字的页面显示原图，同时按阅读顺序使用自带的 Tesseract 英文/简体中文模型识别。识别词坐标转换为透明文字层，接入原有选区、拖放、来源定位和批注。

识别结果按文献 ID、内容修订和页码缓存到本机，重新打开无需重复识别。每篇文献使用一个串行 OCR worker 和有像素上限的临时画布；关闭或切换文献会取消工作。工具 → 目录与全文搜索中的“识别整本扫描文字”可补齐尚未阅读页面，支持停止及再次继续；已识别结果保留。普通问答会先识别当前来源页，再检索原生文字和已识别页面，不在首次提问时等待整本扫描书。

“本页 OCR”可重新识别或校正文字。改变文字后不沿用已经失效的词坐标；校正稿供搜索、引用，并可在校正窗口选择。原 PDF 文件不被改写。

印刷文字的操作体验可以接近原生 PDF，但识别准确率不等于原生文本。复杂数学公式、手写、倾斜或低清扫描，以及部分文字覆盖在大幅扫描图上的混合页面，仍可能需要人工核对或主动执行本页 OCR。

## 提问交互

- 输入 `/` 或点击输入框左侧的 `＋` 按钮打开输出方式菜单。支持中文/英文筛选、方向键、Enter/Tab 选择、Escape 关闭及输入法组合状态。选择后保留可删除的标签，普通文本、除法和 URL 不触发命令。
- 提供交互可视化、流程图、分步推导、对照表、三维演示、结构示意、关系图、过程演示和文字解释。显式选择传入原有结构校验与一次格式修复流程；参数不足时仍可说明具体缺失条件，不编造实验。
- 未选择功能时，原有提示词和自动选择形式保持一致。
- 拖到输出区继续直接解读；拖到输入区只展开接收区域、加入带来源的引用并保留已输入文字和已有回答，等待用户发送。两种路径分别处理原生拖放和应用中的指针拖放，输入区停止事件冒泡，避免重复发送。

## r2 界面与交互修正

- 待机输入框恢复为紧凑单行。多行编辑按内容增高，拖入时临时展开；离开后收回。左侧 `＋` 打开输出菜单，不再往草稿里插入斜杠；键盘 `/` 入口保留。移除延时失焦关闭，重复点击、鼠标选择与键盘导航保持一致。
- Anatomy 使用稳定颜色与编号。图中部件、编号、按钮、说明及相关滑块联动；按钮、标题、说明支持数学排版。压缩图示高度、工具栏和周围留白，短屏进一步限制高度。
- 笔记库和阅读侧栏直接显示可交互图示，与画布共用渲染器。支持保存当前参数、选中部件/节点、三维视角和步骤，重启后恢复；可回到保存状态。Markdown 导出仍为静态文本，Folio 内的笔记与工作区备份保留交互数据。
- 修正关系图缩小反而放大、流程图恢复后选中说明隐藏、数学节点未排版的问题。
- 三维滑块、当前角度、再次旋转和重置同步；旧快照按实际顶点校正角度显示。导出列保留各层 a/b 选择，到达终点后禁用继续计算。
- 置换复合保存并恢复所处步骤；多个实例使用独立箭头标识。手动参数与作品快照同步。过程演示可前进/后退或展开全部，推导默认保留完整步骤。
- 编辑、撤销、重做保留与参数兼容的交互状态。

## 真实扫描复测与发布通道

3 份真实扫描文件、7 页通过本地 OCR、词框和缓存检查。修复单文字块模式造成的双栏交错，提升识别分辨率并优化中英文顺序；手动校正的缓存保留。人工核对的正文区域字符准确率为 98.20%–100%，不代表整页、公式或印章识别水平；详见 [样本、计分方法与局限](ocr-validation-1.0.4.md)。

发布脚本每次上传前自动核对草稿、文件哈希并实传 1 MiB 临时探针。上传过程提供耗时提示和有界超时；中断后先核对远端文件，再决定是否重试，避免重复上传。检查报告与构建证据保留在 CI。

Windows 安装器、blockmap 和 `latest.yml` 配套发布；现有 V1.0.2 用户可通过应用内“检查更新”升级。macOS 和 Linux 使用对应平台安装包。发布前检查见 [工具链流程](toolchain.md)。
