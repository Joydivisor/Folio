# V1.0.0 Beta 本地实施计划

2026-11-04，承接输出体验调研。用户已要求开始实施，全程本地，完成验收前不上传。

1. 默认连续向下阅读：保留逐页模式；按需渲染及释放远页资源；保存页码和页内位置；选文、批注、区域引用、目录和搜索都按实际页面定位。
2. 输出体验：文字偏好和简短回答优先；正文与图同屏；推导连续可读；流程图支持判断、分支和回路；提供展开工作区与版本编辑。
3. 作品连续性：追问携带当前图和交互状态，区分解释与修改，局部变更保持身份和用户修改；失败/取消保留有效结果。
4. Anatomy 通用适配：固定审查版本并保留 MIT 声明；统一、受约束的 JSON 场景协议，经可信绘图库渲染，不执行模型提供的代码。为不同模型提供相同的能力说明、示例与校验反馈；传输层适配 OpenAI 兼容协议及 Claude 原生 Messages。
5. 扩充可验证 3D：保留既有群论模型，明确通用空间图形与机制插图的差别，新增能力写入能力注册表。
6. 离线回归、独立 Electron 交互验收、文档更新；使用递增版本 beta.10 生成本地程序和 Windows 安装包。真实服务测试单独记录，不能用 mock 测试冒充。

实施按上述顺序推进，具体完成项和验证结果记录在本文件末尾。复杂自由代码创作、Anatomy WebGL/turn 引擎及全功能代码 IDE 不混入首批可交付范围。

## 已实现

- PDF / TXT / Markdown 默认连续滚动；保留逐页按钮和模式，记录页码与页内比例。PDF 仅保留附近画布，远页保留尺寸占位。选区涉及的页面保持加载；跨页 Shift 点击、批注、搜索结果、区域引用按真实页码处理。修复展开画布再返回时位置漂移，并清理被释放页面的选择监听器。
- 回答直接进入右侧可编辑画布，正文与视觉内容同屏；文字和短回答偏好优先。流程图支持开始、结束、判断、分支和回路；推导全文连续展示。混合文稿支持稳定 ID 的文字块与图表块，工作区仅由用户手动展开。
- 模型追问收到当前作品、图数据和交互状态；普通解释追加在作品下方。局部更新只允许命名字段，保持其他内容和已有参数；版本菜单、撤销/重做与手工编辑继续可用。错误和停止生成保留有效作品。
- Anatomy `iso-kit.mjs` 固定到提交 `1482e8469b0a9e0d8cc18ea2740a01423d29ae80`，本地随包分发 MIT 许可和来源。所有模型使用相同 JSON 结构，由应用渲染盒体、柱体、弹簧、部件说明和参数平移。没有运行模型生成的代码，也不依赖 Claude Code。
- 传输层支持现有 OpenAI 兼容服务，以及 Claude 原生 `/v1/messages` 与模型列表。Claude 密钥可按既有密钥库方式保存，支持可选 Workspace ID。仅遇到明确“不支持 JSON response_format”的错误时重试普通 JSON 文本模式，仍校验内容并最多修复一次。
- 3D 保留三种群论多面体，并增加球、圆柱、圆锥、自定义顶点和面；支持实体表面/线框、旋转、缩放与状态保存。能力类型在 `DISPLAY_KINDS` 注册，数值与资源边界由各 parser 执行。
- 备份保留新类型、阅读位置与追加解释；学习笔记包含混合文稿、流程内容和结构图说明。更新中英文界面与功能说明。

## 能力边界

| 能力 | 本批边界 |
| --- | --- |
| 模型适配 | 原生 Claude 与 OpenAI 兼容协议；任意其他原生协议需另写传输适配器。协议通用不代表模型的内容质量一致。 |
| Anatomy | SVG 轴测核心子集；最多 80 个部件、4 个控制量，支持受控平移。未移植上游完整 agent 工作流、任意代码生成、turn/WebGL、流体或物理仿真。 |
| 3D | Canvas 2D 投影三维网格；自定义最多 128 顶点、256 面、每面 3–8 顶点。曲面为有限网格，未支持 CAD、外部模型导入、纹理、骨骼及任意着色器。 |
| 画布 | 受约束的混合文稿与图示编辑，最多 12 块；流程图最多 24 节点、48 边。未实现完整代码 IDE、任意 HTML 运行或 ChatGPT 未公开的触发策略。 |
| 生成 | 等待完整 JSON 后校验展示；本批未改成模型 token 流式生成。 |
